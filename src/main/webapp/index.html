🍽️ Canteen Billing System

Welcome to Canteen Billing System

A comprehensive desktop application with web services for managing canteen operations.

📋 Menu Management

Add, update, and manage menu items with categories and pricing

🛒 Order Processing

Place orders with multi-threaded processing

💰 Bill Generation

Automated billing with tax and discount calculations

🗄️ Database Management

JDBC-based SQLite database for data persistence

API Endpoints

Menu API

GET /menu/?action=list

List all menu items

GET /menu/?action=view&itemId=1

View specific menu item

POST /menu/?action=add

Add new menu item (params: itemName, category, price, available)

Order API

GET /order/?action=list

List all orders

POST /order/?action=create

Create new order (params: itemId[], quantity[])

GET /order/?action=view&orderId=1

View order details

Bill API

POST /bill/?action=generate

Generate bill (params: orderId, taxPercentage, discountPercentage, paymentMethod)

GET /bill/?action=view&billId=1

View bill details

GET /bill/?action=list

List all bills

Desktop Application

Launch the GUI application by running:

java -cp target/classes com.canteen.gui.CanteenGUI

Or using Maven:

mvn exec:java -Dexec.mainClass="com.canteen.gui.CanteenGUI"
